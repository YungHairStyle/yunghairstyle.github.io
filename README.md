# Asaad Hanna — academic homepage

Source for [yunghairstyle.github.io](https://yunghairstyle.github.io/), my academic homepage.

The site presents my quantum-algorithms research, computational projects, teaching experience, CV, and scientific reports. It is a static site hosted with GitHub Pages.

- `index.html`: page content and styles.
- `portrait.jpg`: profile photograph.
- `academic-cv.pdf`: public CV.
- `internship-report.pdf`: scientific report on my Sherbrooke internship.
- `entropy-part-1.pdf` and `entropy-part-2.pdf`: unpublished undergraduate research manuscripts.

To update the site, edit the static files and commit to the publishing branch. Open `index.html` locally for a basic preview; verify links on the published site after deployment.

Research documents retain their individual authorship and publication status.
